# Histórico de Engenharia

Este diretório contém os registros especializados das Sprints que não tiveram
commits individuais durante o desenvolvimento.

## Fontes e precedência

Cada registro foi composto por confronto entre:

1. `docs/ENGINEERING_MASTER.md`;
2. histórico Git, commits e tags;
3. `CHANGELOG.md`, `ROADMAP.md`, `README.md` e arquitetura;
4. código, schemas, migrações e testes;
5. livro histórico integral do projeto, mantido como arquivo Pages restrito
   fora do repositório.

O arquivo Pages não é versionado porque é uma transcrição extensa que contém
contexto operacional e potencialmente identificadores clínicos. Seus fatos
técnicos foram extraídos, sanitizados e consolidados nestes documentos.

- objetivo planejado;
- implementação relatada;
- validação automatizada;
- homologação real;

Essa distinção impede que uma intenção registrada no chat seja apresentada
como funcionalidade concluída.
